# vergi_parametreleri (public data repo)
Year-versioned Turkish tax parameters read by the vergi_hesaplama app.

## Rules
- Work only on branch agent-updates. Never push to main. Never force-push.
- Never change a number, rate or bracket without an official cited source and my approval.
- File names, URLs and formats must stay stable; only additive changes.
- Never commit secrets or personal data: this repo is public.
